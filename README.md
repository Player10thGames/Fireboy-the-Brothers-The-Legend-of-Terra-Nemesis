# Fireboy The Brothers - The Legend of Terra Nemesis

A Brand New HTML5 Video Game.

## 🎮 Play the Game

Open `index.html` in any modern web browser to play.

## 🕹️ Controls

### Keyboard
| Action | Keys |
|--------|------|
| Move | Arrow Keys or WASD |
| Jump | Space, W, or Up Arrow |
| Fire | Z, X, J, or K |
| Pause | Escape or P |
| Start/Confirm | Enter or Space |

### Touch Screen (Mobile)
| Control | Location |
|---------|----------|
| D-Pad | Bottom-left |
| JUMP Button | Bottom-right (blue) |
| FIRE Button | Bottom-right (red) |
| Play/Pause | Top-right |

## 🗺️ Stages

### Stage 1: Terra Station
- **Gimmick:** Conveyor Belts
- **Enemies:** Drones, Walkers
- **Boss:** Duo Mecha Rocket - Big Core MK.I

### Stage 2: Inferno Cavern
- **Gimmick:** Lava & Rising Lava
- **Enemies:** Fireballs, Lava Golems
- **Boss:** Fire Breath

### Stage 3: Nemesis Fortress
- **Gimmick:** Spikes & Moving Platforms
- **Enemies:** Mechs, Tanks
- **Boss:** Both Bosses

## 👹 Bosses

### Duo Mecha Rocket - Big Core MK.I
Inspired by the Big Core from Gradius. Features:
- **Phase 1:** Laser spreads, aimed shots, double lasers
- **Phase 2 (50% HP):** Faster attacks + ring burst pattern

### Fire Breath
Inspired by Fire Breath from Sonic 3. Features:
- **Phase 1:** Bomb spreads, dropping bombs, fire streams
- **Phase 2 (50% HP):** Spiral fire pattern + faster attacks
