# Fireboy The Brothers - The Legend of Terra Nemesis (Demo)

A Brand New HTML5 Video Game for Fireboy The Brothers - The Legend of Terra Nemesis.

## 🎮 Play the Game

Open `index.html` in any modern web browser to play!

## 🕹️ Controls

### Keyboard
| Key | Action |
|-----|--------|
| Arrow Keys / WASD | Move |
| Space / Z | Jump |
| X / Shift | Shoot |
| Down + Shoot | Special Attack (when charged) |
| P / Enter / Esc | Pause |

### Touch Screen (Mobile)
| Control | Action |
|---------|--------|
| D-Pad | Move |
| A Button | Jump |
| B Button | Shoot |
| Play/Pause | Pause Game |

## 👥 Characters

| Character | HP | Speed | Jump | Damage | Special |
|-----------|-----|-------|------|--------|---------|
| **Fireboy** | 5 | 4.5 | 11 | 1 | Flame Burst |
| **Caroline** | 3 | 5 | 12 | 1 | Heart Beam |
| **Butch** | 7 | 3.5 | 10 | 2 | Power Slam |
| **Anabel** | 4 | 4 | 11.5 | 1 | Star Storm |

### Special Attacks
- **Fireboy - Flame Burst**: Spreads multiple fire shots in a fan pattern
- **Caroline - Heart Beam**: Fires a powerful piercing beam
- **Butch - Power Slam**: Ground-pound wave that damages all ground enemies
- **Anabel - Star Storm**: Rains stars from the sky across the screen

Charge your special by defeating enemies and collecting pickups!

## 🗺️ Stages

### Stage 1: Terra Outpost
A military outpost on the frontier of Terra. Features moving platforms and fire traps.
- **Boss**: Mega Sentinel
- **Gimmicks**: Moving Platforms, Fire Traps

### Stage 2: Crystal Caverns
Underground caverns filled with crystals and ice. Watch for crumbling platforms!
- **Boss**: Crystal Wyrm
- **Gimmicks**: Crumbling Platforms, Ice Patches

### Stage 3: Infernal Forge
A volcanic factory filled with lava and conveyor belts. The final challenge!
- **Boss**: Big Core MK.I
- **Gimmicks**: Lava Pits, Conveyor Belts

## 👾 Bosses

### Mega Sentinel (Stage 1)
A mechanical guardian with aimed shots, laser sweeps, and homing missiles.

### Crystal Wyrm (Stage 2)
A crystalline dragon that summons crystal rain, charges at players, and fires ice beams.

### Big Core MK.I (Stage 3)
The ultimate boss with multi-shot, laser sweeps, homing missiles, and the devastating Core Beam. Has multiple attack phases that intensify as HP decreases!

## ⚡ Gimmicks

- **Moving Platforms** - Platforms that move horizontally
- **Fire Traps** - Periodic fire bursts from the ground
- **Crumbling Platforms** - Platforms that break when stepped on
- **Ice Patches** - Slippery surfaces with reduced friction
- **Lava Pits** - Instant damage zones
- **Conveyor Belts** - Push the player in a direction

## 📱 Mobile Support

The game features full touch screen controls:
- **D-Pad** for directional movement
- **A Button** for jumping
- **B Button** for shooting
- **Play/Pause** button for pausing

## 🛠️ Technical

- Pure HTML5 Canvas game engine
- No external dependencies required
- 60 FPS game loop
- Procedural level design
- Particle effects system
- Web Audio API for sound
- Responsive design for mobile and desktop
